Система Адаптации

Ссылка на деплой: 
[https://hack-two-rho.vercel.app/](https://hack-two-rho.vercel.app/)

Быстрый старт

Установи зависимости:
npm install
cd backend && npm install && cd ..
cd frontend && npm install && cd ..

Создай базу PostgreSQL и выполни скрипт backend/init.sql.

В файле backend/.env укажи:
DATABASE_URL=postgresql://postgres:твой_пароль@localhost:5432/naumen_hack
JWT_SECRET=super-secret-key-123

Запусти проект из корня:
npm start

Фронтенд: http://localhost:5173
Бэкенд: http://localhost:8080

Как пользоваться

HR

Войди как HR. На дашборде аналитика: средний прогресс, удовлетворенность, сотрудники под угрозой срыва.
Перейди в раздел Сотрудники, выбери Ивана, нажми Назначить план (выбери Java Developer Onboarding).
Перейди в раздел Справочник, там структура команды и контакты.
Наставник

Войди как Наставник. На дашборде список подопечных и их пульс.
Перейди в раздел Задачи на проверку. Проверь задачу Ивана. При нажатии Принять можно выбрать бонусную ачивку (За качество, За инициативу).
Если задача выполнена плохо, нажми Вернуть и оставь комментарий.
Сотрудник

Войди как Сотрудник. На дашборде твой прогресс и пульс.
Перейди в раздел Мой план, нажми На проверку напротив задачи.
Перейди в раздел Достижения, там полученные бейджи, уровень и XP.
Перейди в раздел Справочник, там контакты HR, наставника и коллег.
